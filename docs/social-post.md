## LinkedIn

> **Lumi World — the agent that points, remembers, negotiates, and says no.**
>
> Built today at AI Tinkerers "Agents, Everywhere" in Kuala Lumpur, with team AstraGirls.
>
> Every assistant asks you to describe what is already on your screen. Lumi watches where your attention is instead: hover something, Alt+click, and it is remembered — across tabs, across sessions.
>
> Then you give it one sentence: *"ML laptop, 16 GB RAM, ceiling RM4,000, walk away above it."*
>
> That sentence is a **mandate**, not a prompt. The model parses it once; from then on, whether a limit is met is decided by arithmetic in code, never by the model. Press one button and it runs the whole loop by itself — it reads every listing on the page, drops the ones your mandate rules out, compares what is left, and negotiates in the seller's own chat box.
>
> When the seller counters RM4,150 against a RM4,000 ceiling, Lumi refuses — in the chat, out loud, with the numbers — and walks away. When the price comes back inside the limit, it fills the checkout and places the order. It asks for approval once, at the moment money is committed, and password and card fields are excluded structurally, by one guard every path goes through.
>
> Chrome MV3 · React · React Three Fiber · OpenAI forced tool calling with zod validation. Page content reaches the model as untrusted data, so a hostile page cannot instruct the agent.
>
> An agent that can say no is more useful than one that can only say yes.
>
